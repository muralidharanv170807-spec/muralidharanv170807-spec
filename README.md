## 🚀 Featured Projects

### 01. NexusAI — Autonomous Multi-Agent Data Analyst

An intelligent local analytical workbench that dynamically routes user queries across SQL Analytics, Policy RAG, and Hybrid Audits.

**Key Features:**
- Multi-agent orchestration using LangGraph.
- Local LLM execution using Ollama.
- SQL analytics powered by DuckDB.
- Retrieval-Augmented Generation using ChromaDB.
- Self-evaluated groundedness scoring.
- Interactive Plotly visualizations and CSV exports.

**Tech Stack:** Python, FastAPI, LangGraph, DuckDB, ChromaDB, Ollama, Tailwind CSS, Plotly.js.
